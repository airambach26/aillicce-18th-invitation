## Open and preview
1. Extract this entire ZIP.
2. Open Invitation.code-workspace in Visual Studio Code.
3. Press F5 to preview in Microsoft Edge, or double-click index.html to use your default browser.

No Node.js, npm, extensions, or build step is required.

Edit index.html for page structure, styles.css for styling, and app.js for navigation.
The original designs are assets/1.svg and assets/2.svg. Text within the designs must be edited in the SVG artwork.

## Connect to your existing GitHub repository safely
The ZIP does not include Git credentials or an authenticated connection.

1. In VS Code, press Ctrl+Shift+P and choose Git: Clone.
2. Paste https://github.com/airambach26/aillicce-18th-invitation.git
3. Choose a new local folder, then open the cloned repository.
4. Copy the contents of this extracted project INTO the cloned repository folder, not as a nested folder. Replace index.html only after saving any old version you want to keep. Existing Git history remains intact.
5. Open Source Control, review the changes, enter a message, and choose Commit, then Sync Changes. Complete GitHub sign-in in the browser if requested. Do not share passwords or tokens in chat.

This updates your existing repository without force-pushing or deleting old folders.
To host later, configure GitHub Pages to publish main from /(root). Publishing is separate from opening the project in VS Code.
